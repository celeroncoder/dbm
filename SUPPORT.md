# Support

- File reproducible bugs with the [bug report form](https://github.com/celeroncoder/dbm/issues/new?template=bug_report.yml).
- Propose workflow changes with the [feature request form](https://github.com/celeroncoder/dbm/issues/new?template=feature_request.yml).
- Propose a database adapter with the [adapter form](https://github.com/celeroncoder/dbm/issues/new?template=database_adapter.yml).
- Report security problems through [private vulnerability reporting](https://github.com/celeroncoder/dbm/security/advisories/new).
- Use a normal issue for usage questions after checking the README and [troubleshooting guide](docs/troubleshooting.md).

Sanitize command output. Remove passwords, connection URLs, tokens, private
paths, container environment values, and production data before posting.
This project has no paid support or response-time guarantee.
